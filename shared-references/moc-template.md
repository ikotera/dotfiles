# MOC テンプレート

タイトル＝ファイル名はトピック名（短い名詞句）。日付・"MOC" は含めない。禁止記号は除去（`obsidian-rules.md` の命名規約に従う）。保存先は `02_MOC`。

````markdown
---
type: moc
domain: [<関係する領域。多値可>]
tags: [<vocabulary.md から。多値・任意>]
status: seedling
created: <YYYY-MM-DD>
sources: ["[[束ねる distill]]"]
aliases: [<別名・略語・和英表記>]
---

# <トピック名>

## 一言でいうと
> <このトピック全体を1文で。読み手が最初に掴むべき要点>

## システム図（任意）
![[<11_Images に置いた図ファイル名>.svg]]

## 読み解き方（任意）
- <図や全体像の見方を数行で。詳細は各ノートへ委譲する>

## 構成要素ノード（ハブ）

### <群1の見出し>
- [[ノードA]] — <一言の位置づけ>
- [[ノードB]] — …

### <群2の見出し>
- [[ノードC]] — …

## 関連
- 出自: [[束ねる distill]]（複数あれば frontmatter の sources にも列挙）
- 隣接ハブ / 正本: [[関連 MOC]] ／ [[マニュアル]]
````

- MOC は概念の説明本体を持たない。説明は各 atomic note にあり、MOC は**群別の索引＋全体像**に徹する。
- 図は `11_Images` に SVG として置き、`![[ファイル名.svg]]` で名前埋め込みする（ウィジェット依存の CSS 変数を排した自己完結 SVG にする）。
- `sources` には束ねた distill を列挙する。1トピックが複数セッションにまたがると複数になる。
