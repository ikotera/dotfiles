## §11 確認・計測

- 使用率の取得は会話フックで待たず、親の活動中は180秒間隔、30分無活動で休止する。デスクトップは更新イベントと60秒間隔の再読込を使う。
- `python3 -m unittest discover -s adapters/hermes/plugin/tests` の10件で、消費予測、振替、通知、排他、履歴の刈り込み、休止・再開を確認。Python と JavaScript の構文検査も通過。
- 隔離プロファイルで実際の Hermes ローダーに API をマウントし、未取得時と取得後の GET 200、既定ルートの振替を確認。React のサーバー側描画でチップの使用率と期限切れ表示を確認。実際の gateway でのイベント配信と Desktop 画面での表示は未確認。

## §12 次回に生かす点

- 取得時刻に由来する端数秒でリセット時刻が毎回変わることがある。同一枠の照合から端数秒だけを除き、期限の判定には元の時刻を使う。
